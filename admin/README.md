# B-CODE Admin Dashboard

A modern admin dashboard for managing B-CODE pricing packages and maintenance plans.

## 🚀 Features

- ✅ Authentication (Login/Logout)
- ✅ Package Management (CRUD)
- ✅ Maintenance Plans Management (CRUD)
- ✅ Notifications System
- ✅ Dashboard Analytics
- ✅ Responsive Design
- ✅ Dark Theme

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🔧 Configuration

1. Update `.env` file with your backend API URL:
```env
VITE_API_URL=http://localhost:5001/api
```

2. Make sure your backend server is running on port 5001

## 🎨 Tech Stack

- React 18
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- Lucide React (Icons)
- React Hot Toast

## 📝 Default Login

After creating your first admin user via the backend API, use those credentials to login.
